# ADR-011: Product name "contribusage", lowercase

- **Decided:** 2026-09-28 · **Spec:** SPEC header, §2.3 · **Supersedes:** —

## Context
The name must describe the app and must not contain the name of any integrated tool or vendor (SPEC §2.3).

## Options
No alternatives were recorded.

## Decision
"contribusage" (*contrib*utions plus *usage*), always lowercase in the UI and documentation.

## Consequences
Name availability (stores, domain, trademarks) is checked before the first public release (Q-6, T-6.7).
